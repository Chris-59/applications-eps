# Applications EPS · FDE Perpignan

Applications de Christophe Honthaas (formateur EPS, Faculté d'Éducation de Perpignan) pour préparer l'oral d'EPS du CRPE.

| Fichier | Application |
|---|---|
| `objectif-oral-eps-l3.js` | Objectif oral EPS · L3 (CRPE bac+3) |
| `objectif-oral-eps-m2.js` | Objectif oral EPS · M2 (CRPE bac+5) |

Chaque fichier contient l'application entière. Pour l'afficher dans une page web :

```html
<div id="app-oral-l3"></div>
<script src="https://chris-59.github.io/applications-eps/objectif-oral-eps-l3.js"></script>
```
