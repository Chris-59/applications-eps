# Applications EPS · FDE Perpignan

Applications de Christophe Honthaas (formateur EPS, Faculté d'Éducation de Perpignan) pour préparer l'oral d'EPS du CRPE.

| Fichier | Application |
|---|---|
| `objectif-oral-eps-l3.js` | Objectif oral EPS · L3 (CRPE bac+3) |
| `objectif-oral-eps-m2.js` | Objectif oral EPS · M2 (CRPE bac+5) |
| `crpe-m2-eps.js` | CRPE M2 EPS (100 % concours, sans TD ni suivi de stage) : relances du jury tirées une par une, grille à quatre niveaux (exposé et entretien), second essai sur un sujet parallèle, « Observer avant d'agir », « Améliorer une séance », mini-cas de positionnement, flashcards « Essentiel pour l'oral » ; « Ce que je sais déjà » avant les fiches (tri des notions, puis bilan après lecture ; les notions restées floues rejoignent la révision espacée) et « Je bloque » (aides graduées après un premier essai, dans les exercices ciblés, la préparation de l'oral blanc hors mode examen et le mini-cas). Page crpe-m2-eps.html de l'espace CRPE EPS (non indexé) |
| `crpe-l3-eps.js` | CRPE L3 EPS (100 % concours, sans les TD ni les UE du 1er semestre) : relances du jury tirées une par une, grille à quatre niveaux adaptée à l'épreuve bac+3, second essai sur une question du même type, mini-cas de positionnement, flashcards « Essentiel pour l'oral », distracteurs de quiz revus ; « Ce que je sais déjà » avant les fiches (tri des notions, puis bilan après lecture ; les notions restées floues rejoignent la révision espacée) et « Je bloque » (aides graduées après un premier essai, dans les exercices ciblés, la préparation de l'oral blanc hors mode examen et le mini-cas). Page crpe-l3-eps.html de l'espace CRPE EPS |
| `autoformation-eps-m1-pefe.js` | Autoformation EPS · M1 PEFE (copie de CRPE L3 EPS, stockage séparé) : menu essentiel ou complet, accueil « Aujourd'hui », test de positionnement mis en avant et parcours conseillé, envoi des résultats seulement si une adresse est donnée, rubriques masquables (dont « Sujets d'entretien »), choix possible depuis l'espace formateur, mention « relue par … » sur les fiches APSA. Réglages dans `autoformation-eps-m1-pefe-reglages.json` et attributs `data-site`, `data-courriel`, `data-entretien`, `data-masque`, `data-mode` du `div` |

| `objectif-eps-m1-pefe.js` | Objectif EPS · M1 PEFE · DST d'EPS de l'ECUE 101.2 et application L3 complète (CRPE bac+3) |

| `visites-sipa-tuteur.js` | Visites de stage SIPA · outil du tuteur universitaire (observation, chronomètre, entretien, UE 306 et UE 405, bulletin). Notes enregistrées dans le navigateur uniquement |

Notes enregistrées dans le navigateur uniquement |
| `evaluation-ue506-2-ecrit-reflexif.js` | Évaluation de l'écrit réflexif UE 506.2 (L3) · outil du formateur : grille à sept critères et quatre niveaux, deux curseurs (langue, cohérence), une fiche par copie, relevé des notes, fiches et relevé en PDF (bibliothèques dans `lib/`), export CSV. Notes enregistrées dans le navigateur uniquement |

Notes enregistrées dans le navigateur uniquement |

Notes enregistrées dans le navigateur uniquement |
| `evaluation-dm-ue-304-4-m2-meef.js` | Évaluation du DM de l'UE 304.4 EPS (M2 MEEF) · outil du formateur, construit sur le modèle des outils L1 et L2 : DM collectif noté par groupe (3 à 5 étudiants), grille académique à deux colonnes de 10 points (trois paliers non cumulables, quatre curseurs), import d'une liste d'étudiants (CSV ou texte collé), groupes créés à la main ou automatiquement, une feuille par étudiant en PDF et Word, tableau récapitulatif, export CSV, sauvegarde. Notes enregistrées dans le navigateur uniquement |

Toutes les applications étudiantes ont un **mode concours** (« mode essentiel » pour M1 M2E et M2 M2E) : un bouton du menu réduit le menu aux rubriques choisies, et « Mes réglages » permet de choisir ces rubriques. Les applications démarrent en mode concours, sauf L1 et L2 qui démarrent sur le menu complet ; le choix de l'étudiant (menu complet ou mode concours) est ensuite conservé. Choix enregistrés dans le navigateur uniquement.

Chaque fichier contient l'application entière. Pour l'afficher dans une page web :

```html
<div id="app-oral-l3"></div>
<script src="https://chris-59.github.io/applications-eps/objectif-oral-eps-l3.js"></script>
```
